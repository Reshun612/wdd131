JavaScript concepts practiced

  • Object: aCourse groups course information in key-value pairs.
  • Properties: code, name, logo, and sections store data.
  • Method: enrollStudent() is a function stored in the object.
  • this: this.sections refers to the sections property of the current course object.
  • findIndex(): Finds the position of the section with the matching section number.
  • map(): Creates the table row markup for each section.
