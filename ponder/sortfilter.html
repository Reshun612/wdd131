About This Practice

This activity practices JavaScript array methods, including .sort(), .filter(), .find(), .includes(), and .map(). The examples below let you try sorting and filtering data.

Practice 1: Sorting a Simple Array

Use .sort() with a comparison function to arrange the fruit names alphabetically.

Select the button to see the alphabetized fruit list.

Practice 2: Sorting an Array of Objects

Sort the products by their numeric price, from lowest to highest.

  1. Select the button to sort the products.

Practice 3: Filtering an Array

Use .filter() and .includes() to find animals that have a selected trait.

  • Select a trait to filter the animals.

Putting It All Together: Hike Finder

Search by a hike name, a word in its description, or a tag. The matching hikes are sorted by distance from shortest to longest. A random hike appears when the page first loads.
